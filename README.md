## ✨ Sobre o projeto

**Aurum Weather** é uma aplicação de previsão meteorológica criada com foco em:

- 🎨 Interface moderna e premium
- 🌦️ Experiência visual baseada nas condições climáticas
- 📱 Design responsivo
- ⚡ Performance utilizando Vite
- 📍 Localização automática
- 🔎 Pesquisa de cidades
- 🌡️ Informações meteorológicas em tempo real
- 📅 Previsão para os próximos 5 dias

O projeto foi desenvolvido como parte do meu portfólio de desenvolvimento web.

---

## 🚀 Funcionalidades

### 🌡️ Clima atual

Exibe:

- Temperatura atual
- Sensação térmica
- Umidade
- Velocidade do vento
- Índice UV
- Condição climática
- Cidade e país
